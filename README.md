# 🛍️ Maya AI – Shopping & Styling Assistant

Maya AI is a Telegram-based shopping and styling assistant built using n8n, Google Gemini, and Groq Whisper API. It supports voice and text interactions, provides fashion recommendations, and searches Amazon India products using AI-powered automation and web scraping.

## ✨ Features

* 🛒 AI-powered Amazon product search
* 👗 Personalized fashion & styling suggestions
* 🎙️ Voice message support using Groq Whisper API
* 🤖 Conversational AI with Google Gemini
* 📩 Telegram bot integration
* ⚡ Built completely using n8n workflows

---

## 🧠 Tech Stack

* 🔹 n8n
* 🔹 Telegram Bot API
* 🔹 Google Gemini API
* 🔹 Groq Whisper API
* 🔹 ScraperAPI
* 🔹 Python

---

## ⚙️ Workflow

1. User sends a text or voice message on Telegram
2. Voice messages are converted to text using Whisper API
3. Gemini AI understands the user request
4. Product searches scrape Amazon India results
5. AI generates shopping or styling responses
6. Reply is sent back on Telegram
